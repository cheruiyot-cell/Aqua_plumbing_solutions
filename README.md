AQUA PLUMBING SOLUTIONS WEBSITE — README SUMMARY

Project Overview

A premium, mobile-first, conversion-optimized website for Aqua Plumbing Solutions, a plumbing company serving Nairobi, Machakos, and Kajiado. The primary goal is to drive enquiries via WhatsApp at 0702 555 093.

Technology Stack

Component Technology

Interactivity Vanilla JavaScript (ES6+)
Fonts Fraunces (headings) + Inter (body)
